About Me

Built for
the Game

I'm Matthew Lehman. I photograph Logan Hocking athletics — baseball, soccer, volleyball, tennis and the AFJROTC Raider program — and I'm a student there myself, which is how I end up on the sideline for the games nobody else is covering.

I started Matthew Lehman Media in 2025. Every shoot goes up whole rather than cut down to a few highlights, so an athlete who played the whole game can actually find themselves in it.
